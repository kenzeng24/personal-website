## personal-website

Personal portfolio site for Ken Zeng, built with plain HTML, CSS, and JavaScript. No build step or package manager — files are served directly via GitHub Pages.

Live at: https://kenzeng24.github.io/personal-website/

### Structure

| File | Purpose |
|---|---|
| `index.html` / `index.css` / `waves.js` | Landing page with animated canvas wave effect |
| `main_page.html` / `main_page.css` | Portfolio page with bio, research, publications, and posters |
| `spinning_wheel.js` | Loading overlay animation on the portfolio page |
| `site_nav.js` | Sticky nav with active-link highlighting on scroll |
| `multimodal.js` | Canvas pipeline diagram in the research section |
| `km.js` | Kaplan-Meier survival curve canvas |
